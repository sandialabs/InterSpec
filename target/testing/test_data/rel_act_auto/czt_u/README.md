# JRC CZT uranium spectrum

`CZT500_CBNM-446_@20mm_01.cnf` is one unmodified spectrum from the JRC open data set
https://jeodpp.jrc.ec.europa.eu/ftp/public/JRC-OpenData/UPu-Gamma/ (CZT_U): a Ritec CZT 500S
(500 mm^3, hemispherical) detector 2 cm from the CBNM 446 certified uranium standard (4.46 wt% U-235),
about 28 h live time.  See `COPYRIGHT-JRC.txt` for the licence (CC BY 4.0).

Used by `test_LlmIsotopicsTool.cpp` to run the shipped "CZT-std U (130-1010 keV)" preset; this is the
highest-statistics standard of the set, so it gives the largest tool result.
