Exports the foreground file with any energy calibration changes. "Displayed" formats hold the sum of the displayed samples and detectors. Spectrum files do not include peaks; save them with the peak CSV. N42-2012 and SPE files include the peaks (which InterSpec reads too); for other formats, save the peaks with the peak CSV.

Help
  • Double-click spectrum: fit a peak; Search for peaks (Peaks section) fits them all
  • Right-click a peak: delete, refit, change continuum or skew, or assign a source from the shown reference lines
  • Click a peak's source in the Peaks table to type one, e.g. Cs137, Pb 75, or Th232 S.E.
  • Drag ROI edge: change the fit region
  • Ctrl-drag: fit peaks in a region
  • Shift-drag: erase peaks in a region
  • Drag: zoom in; Cmd/Meta-drag: zoom Y
  • Click the y-axis title to toggle log/linear; click the x-axis title to toggle the energy strip chart
  • Time chart: drag for foreground, hold b for background, s for secondary; add Shift to add, Ctrl to remove; right-drag zooms
  • Peaks saved in N42 or SPE files, by InterSpec or this page, load with the file
  • URL: ?url=<spectrum>&background=<spectrum>

This page is self-contained: everything it needs is inside this one HTML file. It makes no network requests (unless you use the ?url= argument to fetch a spectrum), and nothing you load or analyze is ever sent from your computer.
